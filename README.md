# Todo App

A fully interactive Todo App built with vanilla JavaScript. This project was built to practice real-world frontend development concepts such as state management, DOM manipulation, persistence, and UI architecture.

---

## 🚀 Features

- Add new todos
- Mark todos as complete / active
- Delete todos
- Filter todos (All / Active / Completed)
- Clear completed todos
- Drag and drop reordering
- Light and dark theme toggle
- Persistent data using localStorage
- Responsive design for all devices

---

## 🛠️ Built With

- HTML5
- SCSS (Sass)
- Vanilla JavaScript (ES6+)
- Flexbox & CSS Grid
- LocalStorage API
- Drag and Drop API

---

## 🧠 What I Learned

This project helped me deeply understand:

- State-driven UI architecture (data → UI rendering)
- DOM event delegation
- Array methods like filter, map, and splice
- Managing application state without frameworks
- Persisting data in the browser using localStorage
- Building drag and drop functionality manually
- Separating logic (state) from UI rendering
